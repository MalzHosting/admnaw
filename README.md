# MALZX Admin Website — Vercel

## Deploy
1. Upload seluruh isi folder project ke repository GitHub.
2. Import repository tersebut di Vercel.
3. Framework Preset: Other. Build Command dan Output Directory dikosongkan.
4. Deploy.

## Batasan penting
Project ini sepenuhnya statis. Editor menyimpan HTML dengan `localStorage`, sehingga perubahan hanya tersimpan pada browser/perangkat yang digunakan untuk mengedit. Login juga hanya pemeriksaan sisi browser dan kredensial dapat dilihat dari source JavaScript. Ini bukan sistem admin aman untuk website produksi. Untuk penyimpanan lintas perangkat dan keamanan sungguhan diperlukan backend, database, dan autentikasi server.

Gunakan nama/domain yang kamu miliki dan jangan menyajikan situs ini sebagai layanan resmi pihak lain.
